Guest demo: a quality report on synthetic requirements

About this demo

This page shows a quality report for a fictional order service. The eight requirements were written for this demo and are synthetic. Some of them are deliberately flawed: vague, incomplete or contradictory.

The report was produced offline, once, and published as a fixed file. Nothing on this page is live: you cannot upload, change or re-run anything, and the page sends no data anywhere. The section "How this was produced" below says exactly which steps made each part.

Limits

  • The findings come from a rule-based analyzer, not from a language model.
  • The analyzer matches lowercase word fragments, so different wording can add findings or miss real problems.
  • The findings describe these synthetic requirements only. They say nothing about how the analyzer performs on real documents.
  • The report is not a release decision, and the tests ran against a simulated order service inside the build, not a real system.
